Traduce las decisiones arquitectónicas y los agregados del dominio a rutas, solicitudes, respuestas, permisos, errores y garantías observables. La API propuesta usa REST con JSON para operaciones ordinarias, WebSocket para chat humano y un adaptador de webhooks para pagos. El chatbot inmobiliario conserva su interfaz HTTP independiente.El documento y su contrato complementario openapi.json constituyen una propuesta revisable, no evidencia de implementación o aprobación. Se conserva un monolito FastAPI con nueve módulos, MySQL privado, almacenamiento externo privado y tareas programadas separadas. No se incluyen citas, visitas, negociación, contratos legales, cierre de operaciones, reparto de comisiones ni notificaciones automáticas de matching.Las rutas, DTO, límites de payload y códigos específicos definidos aquí son precisiones nuevas de diseño. Las reglas abiertas de los documentos anteriores siguen pendientes. Ninguna ruta habilita cobros reales, sanciones o publicaciones con políticas sin resolver.
